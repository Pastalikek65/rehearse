# Third-party inventory

Rehearse source is Apache-2.0. `go.mod` has no external Go module dependencies. The compiled CLI includes the Go standard library; its BSD-style notice is included in [`third_party/go.LICENSE`](third_party/go.LICENSE).

| Component | Relationship | License source |
| --- | --- | --- |
| Go standard library 1.27 | Compiled into the CLI | [Go license](https://go.dev/LICENSE) |
| Miniflux 2.2.19 / 2.3.3 | Separate pinned runtime images; database schema used by the synthetic fixture | [Apache-2.0](https://github.com/miniflux/v2/blob/2.3.3/LICENSE) |
| Forgejo 15.0.9 / 16.0.5 | Separate pinned runtime images; adapter observes public API and database structures | [GPL-3.0-or-later declaration](https://forgejo.org/faq/#is-forgejo-licensed-under-the-gpl), [license text](https://codeberg.org/forgejo/forgejo/src/tag/v16.0.5/LICENSE) |
| PostgreSQL 17.11 | Separate pinned database runtime image | [PostgreSQL License](https://www.postgresql.org/about/licence/) |
| curl 8.22.0 | Separate pinned HTTP probe image | [curl license](https://curl.se/docs/copyright.html) |
| Docker Engine and Compose | User-installed external runtime prerequisites | [Engine Apache-2.0](https://github.com/moby/moby/blob/master/LICENSE), [Compose Apache-2.0](https://github.com/docker/compose/blob/main/LICENSE) |

Rehearse does not package Docker, Miniflux, Forgejo, PostgreSQL or curl images into its CLI archive. It downloads pinned images from their upstream registries when needed. Those images also contain upstream dependencies and operating-system packages with their own notices; this direct-component inventory is not an image-wide SBOM. Their licenses and notices remain governed by their publishers. Exact image digests are declared in the [Miniflux adapter source](https://github.com/Pastalikek65/rehearse/tree/main/internal/miniflux) and [Forgejo adapter contract](docs/forgejo-adapter.md). Forgejo is a separate upstream program governed by its upstream license. Rehearse's independently written CLI source is declared Apache-2.0. The CLI archive does not include a Forgejo binary or runtime image. The synthetic Forgejo data example does contain the upstream-generated files listed below; that archive is not covered by a single blanket license statement.

The Miniflux example archive contains synthetic data authored for this project and database structures generated by Miniflux and PostgreSQL. It is not an archive of a user's account. The independently authored synthetic records and fixture text are Apache-2.0; Miniflux's Apache-2.0 license is the same license text supplied in the repository's `LICENSE`, and upstream attribution is preserved here.

## Embedded files in the synthetic Forgejo example

The Forgejo example's `examples/forgejo/forgejo-source-1509.zip` includes an
application data TAR. The independently authored synthetic user, repository,
and file content is Apache-2.0. The TAR also preserves these upstream files
under `./git/repositories/rehearse-fixture/upgrade-fixture.git/hooks/`:

| Embedded paths | Provenance and license notice |
| --- | --- |
| `post-receive`, `pre-receive`, `proc-receive`, `update`, and their matching `*.d/gitea` files | Generated hook scripts from Forgejo 15.0.9. Forgejo declares v9.0 and later GPL-3.0-or-later. The copied scripts also retain inherited Gitea MIT notices. See [Forgejo's license declaration](https://forgejo.org/faq/#is-forgejo-licensed-under-the-gpl), [Forgejo license text](third_party/forgejo.LICENSE), [Gitea license text](third_party/gitea.LICENSE), and the [upstream Gitea license](https://github.com/go-gitea/gitea/blob/v1.22.0/LICENSE). |
| `*.sample` hook files | Git sample hook templates preserved in the repository data. Git's upstream `COPYING` identifies the project license as GNU GPL version 2 unless a file states otherwise. The fixture does not assert which Git release supplied these template files. See [Git's default template documentation](https://git-scm.com/docs/git-init), [Git license text](third_party/git.COPYING), and [upstream Git COPYING](https://github.com/git/git/blob/v2.49.0/COPYING). |

These file-level entries describe the known embedded artifacts, not every
dependency in the separately downloaded runtime images. They make no
image-wide SBOM claim and express no license-compatibility conclusion.
