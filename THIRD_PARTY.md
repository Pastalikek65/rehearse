# Third-party inventory

Rehearse source is Apache-2.0. `go.mod` has no external Go module dependencies. The compiled CLI includes the Go standard library; its BSD-style notice is included in [`third_party/go.LICENSE`](third_party/go.LICENSE).

| Component | Relationship | License source |
| --- | --- | --- |
| Go standard library 1.27 | Compiled into the CLI | [Go license](https://go.dev/LICENSE) |
| Miniflux 2.2.19 / 2.3.3 | Separate pinned runtime images; database schema used by the synthetic fixture | [Apache-2.0](https://github.com/miniflux/v2/blob/2.3.3/LICENSE) |
| Forgejo 15.0.9 / 16.0.5 | Separate pinned runtime images; adapter observes public API and database structures | [GPL-3.0-or-later declaration](https://codeberg.org/forgejo/forgejo/src/tag/v16.0.5/README.md), [license text](https://codeberg.org/forgejo/forgejo/src/tag/v16.0.5/LICENSE) |
| PostgreSQL 17.11 | Separate pinned database runtime image | [PostgreSQL License](https://www.postgresql.org/about/licence/) |
| curl 8.22.0 | Separate pinned HTTP probe image | [curl license](https://curl.se/docs/copyright.html) |
| Docker Engine and Compose | User-installed external runtime prerequisites | [Engine Apache-2.0](https://github.com/moby/moby/blob/master/LICENSE), [Compose Apache-2.0](https://github.com/docker/compose/blob/main/LICENSE) |

Rehearse does not package Docker, Miniflux, Forgejo, PostgreSQL or curl images into its CLI archive. It downloads pinned images from their upstream registries when needed. Those images also contain upstream dependencies and operating-system packages with their own notices; this direct-component table is not an image-wide SBOM. Their licenses and notices remain governed by their publishers. Exact image digests are declared in the [Miniflux adapter source](https://github.com/Pastalikek65/rehearse/tree/main/internal/miniflux) and [Forgejo adapter contract](docs/forgejo-adapter.md). Forgejo remains a separate upstream program; its GPL license does not change the license declaration for Rehearse's independently written CLI. This distribution does not contain a Forgejo binary or copied implementation source.

The example archive contains synthetic data authored for this project and database structures generated by Miniflux and PostgreSQL. It is not an archive of a user's account. Miniflux's Apache-2.0 license is the same license text supplied in the repository's `LICENSE`; upstream attribution is preserved here.

No trademark rights or endorsement by upstream projects are implied.
